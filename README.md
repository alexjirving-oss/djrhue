# DJ RHUE

Booking site for [djrhue.com](https://djrhue.com) — Caribbean & Urban DJ based in Bristol, UK & Malta.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
