# DJ RHUE

Booking site for [djrhue.com](https://djrhue.com) - Caribbean & Urban DJ based in Bristol, UK & Malta.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Booking form

The booking form submits via [FormSubmit](https://formsubmit.co) to `booking.djrhue@gmail.com`. No env vars or GitHub secrets are required.
